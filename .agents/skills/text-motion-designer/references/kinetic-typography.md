# Kinetic typography

Typography is the primary visual material in text-led motion design—not a caption layered over an unrelated animation.

## Establish hierarchy

Define type roles before animating:

- primary statement or headline
- supporting phrase or explanation
- labels, metadata, or annotations
- numeric or data emphasis
- CTA or closing message

Create contrast through size, weight, width, spacing, alignment, position, and timing. Use the project's existing font definitions and tokens.

## Animate meaningful units

Choose the animation unit based on reading order and meaning:

- character: only when the effect requires character-level expression
- word: emphasis or sequential reveal
- phrase: a complete thought or compact message
- line: editorial pacing and structured copy
- text block: a unified statement or layout transition

Do not animate every character merely because it is possible. The animation should support comprehension.

## Legibility

- Preserve sufficient contrast and readable type size.
- Avoid excessive movement while the viewer is reading.
- Avoid overlapping text animations that compete for attention.
- Give important copy a deliberate hold.
- Check the composition at its actual target dimensions and playback size.
- Do not solve crowded layouts by continuously shrinking the type; simplify or sequence the message instead.

Typography should remain intentional in both its still state and its animated state.
