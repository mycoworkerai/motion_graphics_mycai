# Motion principles

Motion should communicate. Every movement should reveal, emphasize, connect, transform, or transition.

## Purpose and hierarchy

- Assign a purpose to each animated element.
- Establish a clear order of attention.
- Avoid making every element move simultaneously.
- Use anticipation and overshoot sparingly.
- Prefer controlled, readable motion over constant bounce.
- Allow moments of stillness so important ideas can land.

## Timing and continuity

- Match duration to the complexity of the movement and the reading task.
- Use consistent easing character across related elements.
- Create rhythm through contrast between activity and rest.
- Maintain continuity between scenes through direction, scale, timing, shape, or color.
- Avoid transitions that obscure the message or create accidental visual jumps.

## Technical boundary

Implement animation with Remotion's deterministic, frame-driven model and the APIs supported by the installed version. Do not rely on CSS transitions, browser timers, or nondeterministic browser behavior for rendered motion.

For exact API signatures and implementation patterns, consult the installed Remotion skills and project documentation rather than copying stale examples into this guide.
