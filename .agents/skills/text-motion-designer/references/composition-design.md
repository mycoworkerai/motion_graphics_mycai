# Composition design

Composition determines where the viewer looks, what they read first, and how the message is understood.

## Establish the frame

Before designing a scene, confirm:

- target width and height
- aspect ratio and viewing context
- safe margins and platform overlays
- focal point and reading direction
- density and expected viewing distance

Do not assume dimensions from a previous project or another composition. Inspect the brief and the repository's existing conventions.

## Build hierarchy

Use:

- alignment to create order
- grouping to show relationships
- negative space to separate ideas
- scale and contrast to establish priority
- consistent spacing to create rhythm
- a clear focal point to guide attention

Avoid crowding the frame or placing essential content near edges where platform UI may obscure it.

## Scene continuity

A composition may change between scenes, but the underlying grid, spacing logic, typography roles, and visual language should remain coherent. Change the layout when the narrative needs a new visual beat—not merely to make every scene look different.
