# Agent workflow

The repository is designed for an AI agent to work locally with the project files and its configured model provider.

## Inputs
A topic or creative brief, target audience, platform/aspect ratio, desired duration, language, and any required product facts or copy.

## Workflow
1. Clarify the communication objective and audience.
2. Propose a central concept and narrative arc.
3. Write concise on-screen copy.
4. Produce a timed storyboard.
5. Define typography, palette, layout, iconography, and motion language.
6. Map the storyboard to scenes and reusable motion components.
7. Implement with Remotion using deterministic frame-based animation.
8. Preview and critique the render.
9. Refine timing, hierarchy, legibility, and transitions.
10. Register and render the final composition.

## Human review
The agent should surface assumptions and ask for approval when a creative decision materially changes the message, brand direction, or scope. Never invent factual claims to make a video more persuasive.

## Separation of concerns
The creative skill should not become a Remotion API manual. The implementation should not make creative decisions by accumulating arbitrary effects. Keep the brief, storyboard, and implementation aligned.
