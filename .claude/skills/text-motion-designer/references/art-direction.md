# Art direction

Build one coherent visual language for the whole video.

Define the emotional tone, palette, typography roles, scale contrast, alignment, spacing, background, shape language, and icon treatment before animating. Prefer existing tokens in `src/index.css`; introduce new colors only when the brief requires them.

Use contrast to establish hierarchy. Keep backgrounds quiet when the message is the hero. Avoid ornamental gradients, glows, shadows, and 3D treatments unless they serve a clear purpose.

Every scene should feel like part of the same system, even when the composition changes.
